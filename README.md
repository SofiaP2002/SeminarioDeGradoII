# SeminarioDeGradoII

Los archivos Cod_final y consolidado_actualizado corresponden a una versión preliminar del dataset utilizada para las primeras etapas de experimentación.  
Actualmente, se continúa trabajando sobre el dataset original almacenado en MySQL, con el objetivo de identificar y evaluar nuevas variables que puedan incorporarse posteriormente al conjunto de datos. Por lo tanto, estos archivos no corresponden aún a la versión definitiva del dataset y podrán ser actualizados a medida que avance el proceso de selección y preparación de variables.
